DYG, quel dev es-tu ?

Un outil web qui scanne un profil GitHub et renvoie, en quelques secondes, un score sur 8 axes, un archétype de développeur et des conseils concrets pour progresser. Sans inscription, gratuit.

  • TypeWeb app · outil gratuit
  • Mon rôleConception & développement full-stack
  • StackVanilla JS · Fastify · PostgreSQL

Le point de départ

Un développeur a un profil GitHub, mais difficile d'en tirer une lecture claire : où suis-je fort, où je pèche, à quoi ressemble vraiment mon travail vu de l'extérieur ? DYG répond à ça sans friction : on entre un pseudo GitHub, et on obtient une analyse immédiate, lisible, actionnable.

Ce que j'ai construit

  • Une analyse d'un profil public GitHub renvoyant un score sur 8 axes et un archétype de développeur.
  • Des conseils concrets pour corriger les points faibles, pas juste un chiffre.
  • Un parcours sans inscription : on entre un pseudo, on a le résultat. Zéro compte, zéro mail.
  • Une interface sombre et soignée, animée, pensée pour donner envie de partager son score.

Côté technique

Front en vanilla JavaScript (zéro framework, chargement léger), back en Fastify qui interroge l'API GitHub, calcule le scoring multi-axes et le persiste en PostgreSQL. L'enjeu : rester rapide et fluide malgré les appels externes, et rendre un résultat instantané côté utilisateur.

  • Vanilla JS
  • Fastify
  • PostgreSQL
  • API GitHub
  • Node.js
