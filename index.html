Qui code votre projet

Je suis Scory, développeur web full-stack freelance basé à Paris. Je conçois et code chaque projet à la main, du design à la mise en ligne, sans template ni page recyclée.

Un seul interlocuteur, de la première maquette au déploiement : moins d'allers-retours, plus de cohérence, et un site qui vous ressemble vraiment. J'aime le code propre, les pages qui chargent vite et les interfaces qui convertissent.
